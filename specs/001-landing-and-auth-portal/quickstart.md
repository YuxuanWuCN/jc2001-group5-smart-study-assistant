## 1. 本地启动服务

在项目根目录启动 FastAPI 本地开发服务器：

```bash
# 方式 A：通过 Python 模块直接启动
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload

# 方式 B：通过根目录执行脚本
python backend/run.py
```

服务启动后，在浏览器访问：  
👉 **`http://127.0.0.1:8000/`**
