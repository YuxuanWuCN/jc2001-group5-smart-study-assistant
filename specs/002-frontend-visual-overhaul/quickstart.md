## 1. 快速启动与本地预览

系统为原生轻量化纯前端与 FastAPI 架构，零构建配置，即开即测：

### 方式 A: 启动全功能 FastAPI 本地后端（推荐）
在命令行中执行：
```powershell
python -m uvicorn backend.app.main:app --reload --port 8000
```
或直接运行便捷启动脚本：
```powershell
python backend/run.py
```
随后在现代浏览器中访问：`http://localhost:8000/`
